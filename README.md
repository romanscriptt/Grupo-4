# Almacén Scan App - Proyecto 2º DAM

## ¿Qué es?
Aplicación móvil multiplataforma para la gestión inteligente de stock. Permite escanear las estanterías de un almacén desde el móvil para controlar los productos disponibles y su uso en tiempo real en sectores como la hostelería, e-commerce y distribución.

## Funcionalidades
- **Escáner móvil:** Identificación de stock en estanterías mediante cámara.
- **Chat interno:** Comunicación directa entre administradores y mozos de almacén/camareros.
- **Agenda y Check-in:** Control de turnos, tareas y registro de asistencia.
- **Multi-sector:** Adaptado para hostelería, tiendas online y logística.
